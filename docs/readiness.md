# Алгоритм расчёта готовности

Файл: `src/lib/readiness.ts`. Реализация прозрачная и детерминированная —
никаких ML-моделей и медицинских прогнозов.

## Нормализация

Каждый ответ анкеты 1–5 приводится к 0..1, где **больше = лучше**:

| Показатель | Направление | Формула |
|---|---|---|
| sleep_score | прямой | (v−1)/4 |
| recovery_score | прямой | (v−1)/4 |
| fatigue_score | инвертирован | (5−v)/4 |
| muscle_soreness_score | инвертирован | (5−v)/4 |
| stress_score | инвертирован | (5−v)/4 |
| mood_score | прямой | (v−1)/4 |

## Итоговый балл

Взвешенное среднее нормализованных компонентов × 100:

```
sleep 0.20 · recovery 0.25 · fatigue 0.20 · soreness 0.15 · stress 0.10 · mood 0.10
```

Это **рабочая эвристика**, а не вероятность травмы. Первичные ответы хранятся
в `morning_checkins`; производные — в `readiness_snapshots` (по одному снимку
на день, upsert по `(athlete_id, snapshot_date)`).

## Вечерняя анкета (состояние дня)

Если за тот же локальный день спортсмена есть post-training анкета, дневной
балл смешивается с вечерним самочувствием:

```
condition = 0.7 × morning_readiness + 0.3 × post_wellness
post_wellness = mean( overall_feeling , inv(leg_fatigue) , inv(arm_shoulder_fatigue) ) × 100
```

Без вечерней анкеты балл дня = только утренней анкете. Если вечерних анкет за
день несколько, берётся последняя по `submitted_at`. Композит применяется
везде: дашборд тренера, аналитика, графики у спортсмена, снапшоты и оценка
алертов — функции `conditionScore` / `dailyConditionSeries` /
`postsByLocalDate` в `src/lib/readiness.ts`.

## Базовая норма (baseline)

- Берутся дневные баллы первых ≤14 дней, в которых есть данные.
- Требуется минимум **8** наблюдений (`MIN_BASELINE_OBSERVATIONS`), иначе
  `confidence = insufficient`, а правила, зависящие от baseline, не срабатывают.
- Считаются среднее и стандартное отклонение.
- Пропуски дней не заполняются нулями — пропущенные даты просто отсутствуют.

## Объяснение (explanation jsonb)

- `band`: good ≥ 70, moderate ≥ 45, low < 45.
- `flags`: `below_personal_baseline` (z > 1.0 ниже среднего ИЛИ абсолютное
  падение ≥ 15 при sd = 0), `low_<component>` для компонентов ≤ 0.25.
- `delta_vs_baseline`: разница с личной нормой в пунктах.

## Рекомендации спортсмену

Тексты берутся из словаря по band: good → «тренируйся по плану»,
moderate → «снизь интенсивность, скажи тренеру», low → «обязательно скажи
тренеру». Таблица `recommendation_texts` содержит переводы ru/ro/en.
